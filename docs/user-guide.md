# User Guide

## Student Flow

1. Register or log in.
2. Browse books.
3. Open a book detail page.
4. Borrow a book using a student ID and book ID.
5. Review current borrowings and fines.

## Admin Flow

1. Log in with an admin account.
2. Open `frontend/admin/dashboard.html`.
3. Manage books, students, borrowings, returns, fines, and reports.

## Local Development

Run the backend first:

```bash
cd backend
mvn spring-boot:run
```

Open `frontend/index.html` in a browser or serve the folder with any static file server.
