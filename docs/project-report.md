# Project Report

## Overview

The Library Management System is a Spring Boot and static HTML application for managing a small library.

## Modules

- Authentication and JWT authorization.
- Book catalog management.
- Student profile management.
- Borrowing and return workflow.
- Overdue fine calculation.
- Summary reporting.

## Technology Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Spring Security
- H2 database for local development
- HTML, CSS, and JavaScript frontend

## Future Improvements

- Add category CRUD endpoints.
- Add role-based endpoint authorization.
- Add pagination and filtering.
- Replace static HTML with React, Vue, or Thymeleaf if required.
